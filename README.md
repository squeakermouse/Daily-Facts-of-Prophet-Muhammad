# Daily Facts — Prophet Muhammad ﷺ

Upload `index.html`, `style.css`, `script.js`, and `night-sky.jpg` to the root of your GitHub repository.

Then go to repository Settings → Pages → Deploy from a branch → `main` → `/ (root)` → Save.

To add a daily entry, edit the `facts` array in `script.js`. Keep a reliable source with every entry.
